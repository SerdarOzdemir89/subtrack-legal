What the chain head means

Each record is sealed with a SHA-256 hash over its canonical fields: case ID, record ID, kind, capture time, coordinates, altitude, accuracy, heading, file name, file hash, note and the previous record's seal. The first record uses sixty-four zeros as the previous seal. The last record's seal is the chain head.

If one field or one file changes, that record no longer matches its seal and every later seal no longer matches the next record's previous seal. The report shows the same head on its verification page.

How to check a record

  1. Open the PDF's verification page and compare the chain head above with the printed head.
  2. For a specific file, recompute its SHA-256 and compare it with the file hash printed on that record's page.
  3. Recompute the record's canonical SHA-256 in the order above, using the previous seal printed on the page. It must equal the record's printed seal.

The seal proves the record has not changed since it was written. It is not a notarisation, legal advice, or a guarantee that a court will admit the record. The network time anchor, when present, is a comparison with a public HTTPS server at export, not a qualified timestamp.

A note on the QR

The QR contains only the chain head and the number of records. It never contains photos, coordinates or notes. Scanning it opens this page in your browser; nothing is uploaded by Proofsheet.
